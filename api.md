# StayEase AI Agent API Contract

This document outlines the REST API endpoints for the StayEase AI Customer Service Agent. It allows frontend applications to interact with the LangGraph-powered AI agent.

---

## 1. Send Message
Sends a guest's message to the AI agent and returns the agent's response. It also flags if the conversation needs to be transferred to a human agent.

**Endpoint:** `POST /api/chat/{conversation_id}/message`

### Path Parameters
| Name | Type | Description |
| :--- | :--- | :--- |
| `conversation_id` | string | Unique identifier for the chat session (e.g., `guest_123`) |

### Request Schema (Body)
| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `message` | string | Yes | The input text message from the guest. |

### Response Schema
| Field | Type | Description |
| :--- | :--- | :--- |
| `reply` | string | The text response generated by the AI agent. |
| `escalated` | boolean | `true` if the request is out of scope and needs human support. |

### Example Request
```bash
curl -X POST "http://localhost:8000/api/chat/guest_123/message" \
     -H "Content-Type: application/json" \
     -d '{"message": "I need a hotel in Sylhet for tomorrow."}'
```
### Example Response (200 OK)
```json
{
  "reply": "I found some great available properties for you in Sylhet:\n- Tea Garden Resort (BDT 5500)\n- Grand Sylhet Hotel (BDT 8000)\n\nWould you like me to book one of these for you?",
  "escalated": false
}
```
### Possible Error Responses
* **400 Bad Request:**
  ```json
  {"detail": "The 'message' field cannot be empty."}
```
```
* **500 Internal Server Error:**
   ```json
   {"detail": "Failed to connect to the LLM service."}
```
```
## 2. Get Chat History
Retrieves the complete conversation history for a specific chat session.

**Endpoint:** `GET /api/chat/{conversation_id}/history`

### Path Parameters
| Name | Type | Description |
| :--- | :--- | :--- |
| `conversation_id` | string | Unique identifier for the chat session (e.g., `guest_123`) |

### Response Schema
| Field | Type | Description |
| :--- | :--- | :--- |
| `history` | array | A list of message objects ordered chronologically. |
| `history[].role` | string | Identifies the sender. Can be `"guest"` or `"agent"`. |
| `history[].content` | string | The actual text content of the message. |

### Example Request
```bash
curl -X GET "http://localhost:8000/api/chat/guest_123/history"
```

### Example Response (200 OK)
   ```json
   {
  "history": [
    {
      "role": "guest",
      "content": "I need a hotel in Sylhet for tomorrow."
    },
    {
      "role": "agent",
      "content": "I found some great available properties for you in Sylhet:\n- Tea Garden Resort (BDT 5500)\n- Grand Sylhet Hotel (BDT 8000)\n\nWould you like me to book one of these for you?"
    }
  ]
}```
